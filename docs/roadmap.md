# VFCS Roadmap

## Milestone 1 - MVP Skeleton (Current)

- monorepo setup with shared model and simulator core.
- frontend shell with palette/workspace/inspector/status.
- core exports and part mapping seed database.
- external integration placeholders.

## Milestone 2 - Editor Interaction

- drag/drop component creation.
- wire drawing and net editing tools.
- basic undo/redo and selection model.

## Milestone 3 - Virtual Chips

- make-chip workflow from selected circuit regions.
- chip library management and versioning.
- chip instantiation and pin remapping.

## Milestone 4 - Export and Integration Expansion

- richer Verilog generation coverage.
- KiCad schematic/netlist translation.
- part-search adapters with normalized result model.

## Milestone 5 - Hardware Bridge

- implementation recommendations by cost/availability.
- package/symbol/footprint linking.
- hardware validation and constraints metadata.
